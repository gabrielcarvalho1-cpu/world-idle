# World Idle

Launcher de jogos idle: catálogo por categoria, vários jogos abertos em abas, aviso de retorno, notas e ranking, e envio de jogos pelos estúdios.

- `index.html`, `style.css`, `app.js`: o site (estático).
- Dados no Supabase (projeto `world-idle`). A chave que aparece no `app.js` é a pública.
